# Submission Checklists

Run the relevant checklist before claiming submission readiness.

## Universal Checklist

- [ ] Venue requirements verified from official source in current session.
- [ ] Main claim is one sentence and appears in abstract + intro.
- [ ] Each claim maps to at least one explicit table/figure.
- [ ] Baseline selection is justified and reproducible.
- [ ] Threats to validity include construct/internal/external/conclusion validity.
- [ ] Limitations section is explicit and non-defensive.
- [ ] Citation list is verified or clearly marked with placeholders.
- [ ] Artifact/reproducibility path is documented.

## Conference Checklist (ICSE, ESEC/FSE, ASE, ISSTA, MSR)

- [ ] Submission is anonymized if required by current policy.
- [ ] Page budget and appendix/supplement policy verified.
- [ ] Required sections for the venue/track are present.
- [ ] Artifact process requirements are addressed (if applicable).
- [ ] Figure/table readability is acceptable in grayscale print.
- [ ] Main narrative fits conference constraints without hidden dependency on appendix.

## Journal Checklist (TSE, TOSEM, EMSE)

- [ ] Journal formatting package is correct for the target journal.
- [ ] Methods and setup detail level supports journal expectations.
- [ ] Additional robustness/generalizability evidence is included.
- [ ] Replication package plan is explicit (data, code, scripts, environment).
- [ ] Ethical/data-use statements and required metadata are complete.

## Camera-Ready Checklist

- [ ] Author metadata and acknowledgments updated as required.
- [ ] Final references have no unresolved placeholders.
- [ ] Figure/table numbering and cross-references are correct.
- [ ] Broken links and stale appendix references removed.
- [ ] Final PDF passes format checks from official instructions.
